Features

From a passing idea to a real plan.

Collect, share, vote, and schedule—all in one friendly place.

📦

テーマごとにBOXを作成

旅行、週末のお出かけ、食べたいものなど、目的に合わせていくつでも整理できます。

🤝

招待コードですぐ共有

6文字のコードやリンクを送るだけ。同じBOXを複数人でリアルタイムに更新できます。

👍

「アリ！」で熱量を共有

いいと思った分だけ何度でも投票。長押しなら、気持ちのままに連続で送れます。

🔗

Webページからかんたん追加

共有シートやURL入力から、タイトル・画像・住所などを自動で取り込みます。

🗺️

地図で場所をチェック

住所のある候補は地図で確認。お店やスポットのWebサイトもすぐ開けます。

📅

決まったらカレンダーへ

日時を選んでカレンダーに保存。候補から予定へ、迷わず次の一歩に進めます。

📦

Create a box for every theme

Keep trips, weekend ideas, restaurants, and shared wish lists neatly separated.

🤝

Share with an invite code

Send a six-character code or link and update the same box together in real time.

👍

Show how much you like it

Vote as many times as you mean it. Press and hold when one “Yes!” is not enough.

🔗

Add ideas from the web

Use the share sheet or paste a URL to import available titles, images, and addresses.

🗺️

Check the place on a map

Preview ideas with an address on the map and jump back to the original website.

📅

Turn a favorite into a date

Choose a time and save it to your calendar when the group is ready to go.
